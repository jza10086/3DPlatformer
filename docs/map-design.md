# 灯塔群岛：从参考案例到完整地图

## 为什么重做

旧版 Skyline Sprint 是约 100 米、三个分区的直线浮台短原型。它足够验证跳跃，却不具备完整地图的空间关系、路线选择和环境记忆点。新版的目标不是重复铺更多跳台，而是让玩家经历一次「从海港出发、绕岛上升、最终抵达灯塔」的完整旅程。

## 可核验的案例与转译

### 1. The Whirlygig：机关教学与复用

Mediatonic 设计师在 [PlayStation 官方博客](https://blog.playstation.com/?p=333768) 中讨论了扫杆、台阶、风扇，以及高手把扫杆转化为冒险捷径的玩法。这里采纳的是**机关有清晰形态、先单独出现、后组合复用**，不是其碰撞弹射模型。

落地：第二区的两次扫杆都在宽阔庭院中，先看见虚线危险圈；玩家可以跳过，也能走更远的草地边线。第六区再次使用同类扫杆，再接入已经能读懂的短跳和节奏门。

### 2. Treetop Tumble：多层路径与失败缓冲

[Fall Guys 官方第五季介绍](https://www.fallguys.com/news/fall-guys-season-5-blog?lang=en-US) 明确描述 Treetop Tumble 的多层、分支路线。官方截图中的连续绿地、对比色机关也提供了可读性的参考。

落地：第三区下路宽、绕行长；上路窄、直接横穿。上层下面有实体恢复层，失误不是自动死亡；可以回到低路继续。两路在同一存档点汇合，不用分路专属状态，也不能漏过存档作弊完赛。

### 3. Human Fall Flat / Castle：可辨识的世界

[官方商店与城堡截图](https://store.steampowered.com/app/477160/Human_Fall_Flat/) 展示由木桥、门楼、高塔和低多边形岩体组成的连续空间，商店说明也强调多路线。这里提取的是**有目标的空间组织**，而不是其抓取、摆荡或布娃娃物理解谜。

落地：高 19 米的条纹灯塔位于路线中心，下面是最终广场；各区有风车、吊机、渡台和桥墩等不同轮廓。海面和岩体把路线连接成群岛环境，近距离镜头读落点，全图视角读整段旅程。

## 总体结构

- 平面路线：港口 → 西侧风车庭院 → 北部双路 → 东侧渡台港 → 南侧山脊 → 中央灯塔。
- 纵向路线：从海港地面 0 米升到终点 16 米。
- 六区、五存档；存档均在稳定的大平台，不放在危险扫掠范围内。
- 主路实测通关轨迹约 400 米；长度是规模指标，不把首玩时长伪装成测得结果。
- 分区的安全停顿、地标和不同地貌，比简单增加机关数量更重要。
- 主路有宽肩、恢复平台和可选择的安全绕行；障碍允许被理解，而不是依赖看不见的碰撞体。

## 保留的边界

普通白方块；原移动参数、短按/长按跳跃、土狼时间和跳跃缓冲；单人计时与快速失败重试。没有擅自添加角色皮肤、抓取、布娃娃、多人、关卡选择大厅、商店或账号系统。

## 可读性与镜头

安全地面使用石色与青绿，动态危险物使用橙红，存档和终点使用金色。路面箭头、旗帜、段落牌、扫杆范围虚线和节奏门灯光共同工作，不能只依靠颜色辨别。

跟随镜头只在落地且移动时缓慢转向路线前方，跳跃时稳定控制方向。Tab 展示真实 3D 全图，并暂停玩家、障碍和计时；返回时保持原先暂停状态。

## 验证原则

地图几何和导航信息可以被测试观察，但测试不得直接推进进度、传送玩家、改速度、关闭危险物或自动设置完赛。主路、上层捷径各需从起点正常输入跑通；独立状态测试允许搭建初始位置，但不能拿这种测试代替真实通关证据。
